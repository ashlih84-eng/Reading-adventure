# Accessibility

Interactive activities use native buttons, labels, visible focus styles, and equivalent ordering controls for pointer and keyboard users. Reading preferences include Reduce Motion, high contrast, passage scale, line spacing, dyslexia-friendly font, and calm reading mode. System `prefers-reduced-motion` is also honored.

Speech recognition differs across browsers and may be unavailable, inaccurate, or require permission. Every oral-reading activity must retain a no-microphone supported path. Transcript comparisons are instructional estimates, not diagnoses.
