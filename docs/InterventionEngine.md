# Intervention engine

Recommendations require at least two low-scoring observations for the same skill. A single poor attempt never lowers placement or creates an intervention. Rules cover vowel patterns, blends/digraphs, context clues, sequencing, main idea, repeated unclear words, decoding/comprehension differences, and comprehension/oral-fluency differences.

Supported responses include shorter passages, listen-then-read, vocabulary previews, word-pattern mini-lessons, parallel passages, retelling, parent review, and reassessment. Records are stored per player and shown positively to children and descriptively in the parent dashboard.
