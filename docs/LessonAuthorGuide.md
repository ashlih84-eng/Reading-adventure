# Lesson Author Guide

Lessons are objects validated by `lessonSchema`. Each needs an ID, region, kind, title, mission, passage, at least two activities, reward, and target skills. Supported Region 1 activity types include read aloud, recognition, sequencing, main idea, retelling, vocabulary, sentence building, evidence, and written response.

Add future region collections beside `sprinkleMeadows.ts`, validate them at load time, and keep content age-respectful. Presentation themes and restoration effects belong to region metadata rather than passage text.
