# Parent Dashboard

The parent area is protected by each player’s PIN (initially `2468`). It shows placement, instructional and independent estimates, region, lesson count, reading minutes, mastery, unclear words, and benchmark progress. Controls support child selection, microphone access, notes, reassessment, isolated reset, and text-report export.

All reports state: “This app provides instructional estimates and is not a formal diagnostic assessment.” Cloud sync remains optional future work; local IndexedDB is authoritative today.
