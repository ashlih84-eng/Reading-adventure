# Parent settings

Each child stores microphone permission, notes, audio levels, accessibility preferences, reading layout, intervention history, and progress independently. PIN changes require the current PIN and a new 4–8 digit PIN. PIN fields use password inputs and are never rendered as visible values.

Master mute and volume controls currently follow the selected child, allowing different sensory settings for siblings. Reassessment and reset act only on the selected child. Export creates a local text report without sending data to a server.
