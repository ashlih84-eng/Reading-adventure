# Placement System

Placement begins at a difficulty suggested by a parent-provided grade range, then moves up or down using demonstrated responses. It samples several skills, stops after repeated difficulty, and recommends a level below frustration. `PlacementResult` records bands, skill estimates, strengths, support needs, confidence, task count, fallback use, and the instructional-estimate disclaimer. Reassessment appends a new result to the player’s history.

Placement is not a diagnosis. Speech support is optional and never blocks completion.
